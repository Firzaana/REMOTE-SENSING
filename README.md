# Data Heat Island - Riset Remote Sensing

Penelitian dampak panas data center AI terhadap lingkungan sekitar memakai citra satelit (Google Earth Engine). Paper acuan: Marinoni et al. (2026), arXiv:2603.20897.

## Fokus saat ini (sesuai spreadsheet TIMELINE REMOTE SENSING)
1. `01_perumusan_dan_perancangan_penelitian/` - ROI dan rentang waktu, studi literatur, uji metode skala kecil, persamaan dan parameter
2. `02_pengumpulan_dan_prapemrosesan_data/` - dataset, cek ketersediaan data, algoritma kebersihan data, QC tahap 1, evaluasi sampel

## Kode
